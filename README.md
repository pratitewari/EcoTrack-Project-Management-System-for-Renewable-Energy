Project Management for renewable energy projects requires a strong project management beside the infrastructure (land etc) and regulatory approvals. Budgets and expenses for each budget head (or budget line) needs to be controlled. Set of equipments for energy generation requires procurement, inventory and regular maintenance.
There is a need for project management system for managing the project details, budget, keeping track of expenses, managing the inventory of equipments and their maintenance records

# SOLUTION
Web based project management system for renewable energy projects with following features:
1.Project Management – Start date, work items and other details
2.Budget – in the form of budget lines or budget heads.
3.Expenses – for each budget lines.
4.Equipment – project equipments with installation date and warranty date.
5.Equipment maintenance records – for keeping track of periodic maintenance and repairs
6.Project work items – project implementation details wit achievable targets/deadlines
7.Users – user id/password for the application user
